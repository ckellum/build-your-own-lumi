The one-minute version

1 · Memory decides what fits

Downloads are usually compressed to about 4 bits per number, so a model needs about 0.6 GB per billion parameters, plus a little for the conversation. 8 GB runs about 8B models, 16 GB about 14B, 24–32 GB about 30B.

2 · Memory speed decides how fast

Every word it writes reads the whole model from memory. A fast GPU with a small model talks fastest; a big memory with a modest speed (like Lumi's computer) fits bigger models.

3 · Small models have limits

Great for chat, summaries, transcription, search and home control. Weaker at hard reasoning, long tasks and reliable tool use. They can be confidently wrong.

4 · Use both

Local for private, offline and always-on jobs. Frontier for hard problems. Frontier to build, local to run: that's how Lumi was made.
